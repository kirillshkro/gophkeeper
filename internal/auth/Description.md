# internal/auth

## Назначение

Пакет `auth` реализует аутентификацию пользователей GophKeeper. Аутентификация
выполняется через передачу заголовка `Authorization` HTTP-запросов. Пакет
определяет, что пользователь — тот, за кого он заявляет.

Пакет не проверяет *разрешение* доступа к данным (это `authz`) — он только
идентифирует пользователя из токена.

## Отвечает за

- проверку credentials пользователя при входе (пароль против хэша);
- выпуск аутентификационного токена после успешной проверки;
- валидацию токена из заголовка `Authorization: Bearer <token>`;
- идентификацию текущего пользователя запроса;
- срок действия токенов и возможность их отзыва.

## Требования

### Функциональные

1. Проверка credentials:
   - получать логин и пароль из запроса;
   - искать пользователя через `user`;
   - проверять пароль через `security.VerifyPassword`.
2. Выпуск токена:
   - после успешной проверки создать токен с данными владельца;
   - задать срок действия (TTL) токена;
   - подписать/зашифровать токен (через `security`).
3. Валидация токена:
   - извлекать токен из `Authorization` заголовка;
   - проверять подписание/целостность и срок действия;
   - вернуть идентификатор владельца токена.
4. Отзыв токена (ревокация):
   - возможность отозвать токен (logout, смена пароля, блокировка аккаунта).
5. Защита от перебора паролей:
   - ограничивать количество попыток за единицу времени;
   - блокировать/задерживать при превышении лимита.

### Неразметочные

- Возврат `(value, error)`.
- Секреты, ключи и пароли **не должны попадать в логи** (`slog`) и в ответы.
- Исчерпывающая godoc-документация.
- Покрытие тестами не менее 70%.
- Токен не должен содержать чувствительных данных в открытом виде.

## Ожидаемое API

- `Verify(login, password) error` — проверка credentials (через `user`+`security`).
- `IssueToken(ownerID string) (Token, error)`.
- `Validate(token string) (User, error)` — из `Authorization: Bearer <token>`.
- `Revoke(tokenID string) error`.
- Тип `Token` (payload, signature, expiry).
- Ошибки: `ErrInvalidCredentials`, `ErrTokenExpired`, `ErrTokenInvalid`,
  `ErrTooManyAttempts`, `ErrUserNotFound`.

## Зависимости

- `gophkeeper/internal/user` (получение хэша/профиля).
- `gophkeeper/internal/security` (хэширование, подписание, отзыв).

Не зависит от `api`, `sync`, `client`, `cli` (ниже уровня представления).
