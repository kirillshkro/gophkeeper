# internal/config

## Назначение

Пакет `config` реализует конфигурацию приложения GophKeeper: настройки
сервера и клиента. Пакет отвечает за «как система настроена» — параметры,
выбор хранилища, форматы.

## Отвечает за

- конфигурацию сервера (сеть, хранилище, безопасность);
- конфигурацию клиента (сервер, локальное хранилище, аутентификация);
- загрузку конфигурации из файла/флагов/переменных окружения;
- валидацию конфигурации.

## Требования

### Функциональные

1. Конфигурация сервера:
   - адрес/порт слушателя;
   - выбор хранилища и формат хранения данных;
   - параметры безопасности (TLS, срок действия токенов);
   - ограничения (лимиты на запросы, размер данных).
2. Конфигурация клиента:
   - адрес удалённого сервера;
   - выбор локального хранилища и формат хранения;
   - параметры аутентификации (токен);
   - параметры синхронизации (интервал, таймауты).
3. Загрузка конфигурации:
   - из файла (например, TOML/YAML/JSON);
   - из флагов CLI;
   - из переменных окружения (при необходимости);
   - приоритет: флаги > переменные > файл.
4. Валидация:
   - проверять значения при старте;
   - ошибка, если конфигурация некорректна.
5. Секреты:
   - пароли/токены не должны попадать в логи (`slog`) и в ответы.

### Неразметочные

- `(value, error)`.
- Исчерпывающая godoc-документация.
- Покрытие тестами не менее 70%.
- Конфиг должен быть расширяемым (новые параметры не ломают старые).
- Не более 250 строк на файл.

## Ожидаемое API

- `LoadServerConfig(path string) (ServerConfig, error)`.
- `LoadClientConfig(path string) (ClientConfig, error)`.
- Структуры `ServerConfig`, `ClientConfig`.
- `ValidateServer(cfg ServerConfig) error`, `ValidateClient(cfg ClientConfig) error`.
- Ошибки: `ErrConfigMissing`, `ErrConfigInvalid`, `ErrUnknownStorageType`.

## Зависимости

- `gophkeeper/internal/storage` (формат/тип хранилища для валидации).
- Стандартная библиотека.
- Не зависит от `api`, `sync`, `client`, `cli`, `user` (ниже уровня).
