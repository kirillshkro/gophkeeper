# internal/version

## Назначение

Пакет `version` предоставляет информацию о сборке GophKeeper: номер версии и
дату сборки. Это вспомогательный пакет без бизнес-логики.

Информация о версии/дате сборки должна быть доступна для CLI (`version`) и
сервера (логирование, статус).

## Требования

### Функциональные

1. Предоставить номер версии (semantic versioning):
   - основной/второстепенный/третьий (MAJOR.MINOR.PATCH);
   - поддержка pre-release/build-меток.
2. Предоставить дату/время сборки:
   - формат `YYYY-MM-DD` или ISO 8601;
   - задаётся через `-ldflags` при сборке.
3. Предоставить способ отображения:
   - строка версии (только номер);
   - полная строка (версия + дата + build).
4. Поддерживать встраивание через Go standard:
   - переменные, заданные через `-ldflags -X main.version=...`.
5. (Необязательно) Предоставить git commit/hash при сборке.

### Неразметочные

- `(value, error)` — при необходимости.
- Исчерпывающая godoc-документация.
- Покрытие тестами не менее 70%.
- Пакет должен быть стабильным (модулярным).
- Не должен зависеть от других пакетов модуля.
- Не более 250 строк кода.

## Ожидаемое API

- `Version() string` — номер версии.
- `BuildDate() string` — дата сборки.
- `BuildCommit() string` — git commit (необязательно).
- `String() string` — полное отображение (версия + дата + commit).
- `Short() string` — сокращённый формат.

## Зависимости

- Стандартная библиотека.
- Не зависит от других пакетов.
