# internal/cli

## Назначение

Пакет `cli` реализует интерфейс командной строки (CLI) клиента GophKeeper.
Это слой представления для CLI: субкоманды, парсинг флагов, вывод в терминал.

Пакет не содержит бизнес-логики — он делегирует работу в ядро клиента
(`client`).

## Отвечает за

- регистрацию нового пользователя (команда `register`);
- управление данными (`add`, `get`, `edit`, `delete`);
- синхронизацию данных (`sync`);
- информацию о версии и дате сборки бинарного файла (`version`);
- парсинг флагов CLI.

## Требования

### Функциональные

1. Поддерживать платформы: Windows, Linux, Mac OS (переносимость CLI).
2. Реализовать субкоманды:
   - `register` — регистрация;
   - `login`/`auth` — аутентификация;
   - `add`/`create` — создание данных;
   - `get`/`show` — отображение данных;
   - `edit` — редактирование;
   - `delete` — удаление;
   - `sync` — синхронизация;
   - `version` — версия и дата сборки.
3. Вывод информации о версии и дате сборки.
4. Обработка ошибок:
   - понятные сообщения об ошибках;
   - правильные коды выхода (0 — успех, !=0 — ошибка).
5. Парсинг флагов:
   - positional args;
   - flags (`-h`, `--help`, `-v`);
   - подкоманды.
6. Вывод данных:
   - таблица/список в терминал;
   - форматирование (например, `tabwriter`/`text`).

### Неразметочные

- `(value, error)`.
- Вывод через `slog` (структурные логи), не через `fmt`.
- Исчерпывающая godoc-документация.
- Покрытие тестами не менее 70%.
- Не более 250 строк на файл.
- Методы принимают не более двух параметров.

## Ожидаемое API

- `Run(cfg *config.ClientConfig) error` — точка входа CLI.
- `parseFlags(flags *flag.FlagSet) *Options`.
- Структура `Options` (флаги CLI).
- Субкоманды (функции/структуры):
  - `CmdRegister(cfg, opts) error`;
  - `CmdLogin(cfg, opts) error`;
  - `CmdAdd(cfg, opts) error`;
  - `CmdGet(cfg, opts) error`;
  - `CmdEdit(cfg, opts) error`;
  - `CmdDelete(cfg, opts) error`;
  - `CmdSync(cfg) error`;
  - `CmdVersion() error`.
- Ошибки: `ErrUsage`, `ErrNoArgs`, `ErrHelp`.

## Зависимости

- `gophkeeper/internal/client` (ядро клиента).
- `gophkeeper/internal/config` (конфигурация).
- `gophkeeper/internal/version` (версия/дата сборки).
- Стандартная библиотека `flag`, `os`.
