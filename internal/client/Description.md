# internal/client

## Назначение

Пакет `client` реализует ядро клиента GophKeeper: взаимодействие с удалённым
сервером со стороны клиента. Это слой бизнес-логики клиента.

Пакет не содержит HTTP-хендлеров (только клиентские вызовы к серверу) и не
зависит от CLI (CLI — слой выше).

## Отвечает за

- аутентификацию пользователя на удалённом сервере;
- доступ к приватным данным по запросу;
- создание/редактирование/удаление данных (на стороне сервера или клиента);
- синхронизацию данных с сервером;
- работу с локальным хранилищем.

## Требования

### Функциональные

1. Аутентификация:
   - отправлять `Authorization` заголовок при каждом запросе;
   - обработать ошибки аутентификации (перелогин, истёк токен);
   - сохранить токен/сессию между запросами.
2. CRUD данных:
   - создание данных (отправка на сервер);
   - чтение/обнаружение данных по запросу;
   - редактирование;
   - удаление.
3. Синхронизация:
   - отправка локальных изменений на сервер;
   - получение изменений с сервера;
   - сохранение в локальное хранилище;
   - разрешение конфликтов.
4. Локальное хранилище:
   - выбор/формат локального хранилища (из `storage`);
   - сохранение локальных данных (через `security`).
5. Многопоточность:
   - независимые операции (загрузка, синхронизация) — через горутин;
   - защита от гонки (mutex/канал).

### Неразметочные

- `(value, error)`.
- Не должна содержать HTTP-хендлеров (только клиентские вызовы).
- Исчерпывающая godoc-документация.
- Покрытие тестами не менее 70% (с мок-сервером/transport).
- Токены/пароли не в логах (`slog`).
- Не более 250 строк на файл.
- Клиент должен быть идемпотентен: повторный запуск запроса — безопасен.

## Ожидаемое API

- `NewClient(cfg *config.ClientConfig) (Client, error)`.
- Интерфейс/структура `Client` с методами:
  - `Register(user *data.User) error`;
  - `Login(login, password string) (Token, error)`;
  - `CreateData(item data.Item) error`;
  - `GetData(id string) (data.Item, error)`;
  - `UpdateData(id string, item data.Item) error`;
  - `DeleteData(id string) error`;
  - `Sync() error`;
  - `Logout() error`.
- Ошибки: `ErrAuthFailed`, `ErrNotFound`, `ErrConflict`, `ErrNetwork`,
  `ErrServer`.

## Зависимости

- `gophkeeper/internal/protocol` (контракт).
- `gophkeeper/internal/data` (типы данных).
- `gophkeeper/internal/storage` (локальное хранилище).
- `gophkeeper/internal/auth` (токены — общая логика).
- `gophkeeper/internal/security` (шифрование локальных данных).
- `gophkeeper/internal/sync` (синхронизация).
- Стандартная библиотека `net/http`.
