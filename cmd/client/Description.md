# cmd/client — точка входа CLI

## Назначение

Пакет `main` (командный интерфейс, binary) — точка входа CLI клиента
GophKeeper. Он собирает и запускает CLI-приложение.

Пакет не содержит бизнес-логики — он только собирает компоненты и управляет
запуском CLI.

## Отвечает за

- загрузку конфигурации клиента (файл/флаги);
- инициализацию ядра клиента (`client`);
- запуск CLI-команд (`cli`);
- обработку флагов CLI;
- обработку ошибок и кодов выхода;
- информацию о версии/дате сборки.

## Требования

### Функциональные

1. Поддерживать платформы: Windows, Linux, Mac OS (переносимость).
2. Загрузить конфигурацию клиента (файл/флаги).
3. Инициализировать ядро клиента (`client`).
4. Запустить CLI-команды (`cli`).
5. Обработка ошибок:
   - понятные сообщения об ошибках;
   - правильные коды выхода (0 — успех, !=0 — ошибка).
6. Информация о версии/дате сборки (через `version`).

### Неразметочные

- `(value, error)`.
- Исчерпывающая godoc-документация.
- Покрытие тестами не менее 70%.
- Не должно содержать бизнес-логики (SOLID).
- Не более 250 строк кода.
- Вывод через `slog` (не `fmt`).
- Методы принимают не более двух параметров.

## Ожидаемое API

- Функция `main()`.
- `run() error` — запуск CLI.
- `parseFlags() *cli.Options` — парсинг флагов.
- Ошибки: `ErrConfigLoadFailed`, `ErrClientInitFailed`, `ErrCLIStartFailed`.

## Зависимости

- `gophkeeper/internal/cli`.
- `gophkeeper/internal/config`.
- `gophkeeper/internal/client`.
- `gophkeeper/internal/version`.
- Стандартная библиотека `flag`, `os`, `slog`.
