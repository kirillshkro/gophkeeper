# tests-specs — `gophkeeper/internal/client` (ядро клиента)

## 1. Общие положения

- Инструменты: `go test -v -race -cover`, `go.uber.org/mock`, `net/http/httptest` (mock-сервер) и кастомный `http.RoundTripper`.
- Пакет не содержит HTTP-хендлеров — только клиентские вызовы.
- Имена: `TestClient_<Метод>_<Сценарий>`, например `TestClient_Login_Failed`.
- Ключевой принцип: **идемпотентность** (повторный запуск запроса безопасен) — проверяется отдельно.

## 2. Моки

| Зависимость | Заменитель |
|---|---|
| `storage.Storage` (локальное хранилище) | gomock / in-memory адаптер |
| `security` (шифрование локальных данных) | gomock / реальные |
| `sync` | gomock |
| HTTP-сервер | `httptest` + кастомный `RoundTripper` (контроль статусов, таймаутов, ошибок) |
| `config.ClientConfig` | реальные значения |

## 3. Группы тестов

### 3.1. Конструирование — `NewClient(cfg *config.ClientConfig) (Client, error)`

| # | Сценарий | Ожидаемо |
|---|---|---|
| 1 | Валидный `ClientConfig` | `Client`, `nil` |
| 2 | Неверный адрес сервера | ошибка (невалидный URL) |
| 3 | Неизвестный тип локального хранилища | `ErrUnknownStorageType` |
| 4 | Отсутствие локального хранилища | ошибка инициализации |

### 3.2. Аутентификация — `Register`, `Login`, `Logout`

| # | Сценарий | Ожидаемо |
|---|---|---|
| 1 | `Login` — успех (сервер 200 + токен) | `(Token, nil)`; токен сохранён для последующих запросов |
| 2 | `Login` — 401 | `ErrAuthFailed` |
| 3 | `Register` — успех | `nil`, сессия создана |
| 4 | `Register` — 409 (login taken) | ошибка (не `ErrNetwork`) |
| 5 | `Logout` | токен отозван на сервере, локальное состояние сброшено |
| 6 | Истёк токен → авто-перелогин (если реализовано) | новый токен, запрос повторён, `nil` |
| 7 | `Authorization` заголовок в каждом запросе | присутствует, токен валиден |

### 3.3. CRUD данных — `CreateData` / `GetData` / `UpdateData` / `DeleteData`

| # | Метод | Сценарий | Ожидаемо |
|---|---|---|---|
| 1 | `CreateData` | валидный объект, сервер 201 | `nil`, объект сохранён локально |
| 2 | `CreateData` | сервер 400/409 | соответствующая ошибка (`ErrConflict`/валидация) |
| 3 | `GetData` | объект существует | `(Item, nil)` |
| 4 | `GetData` | объекта нет (404) | `ErrNotFound` |
| 5 | `UpdateData` | свой объект, валидная версия | `nil` |
| 6 | `UpdateData` | устаревшая версия (409) | `ErrConflict` |
| 7 | `UpdateData` | чужой объект (403) | `ErrUnauthorized`/серверная ошибка |
| 8 | `DeleteData` | свой объект | `nil` |
| 9 | Любой метод | сетевая ошибка / таймаут | `ErrNetwork` |
| 10 | Любой метод | сервер 500 | `ErrServer` |

### 3.4. Синхронизация — `Sync()`

| # | Сценарий | Ожидаемо |
|---|---|---|
| 1 | Успешная синхронизация (upload + download) | локальное == серверное, `nil` |
| 2 | **Идемпотентность:** повторный `Sync` | тот же результат, данные не дублируются/не теряются |
| 3 | Конфликт (разрешение в `sync`) | локальное состояние согласовано, `nil` |
| 4 | Сетевая ошибка во время синхронизации | данные не повреждены; повторный `Sync` — безопасен |
| 5 | Параллельные `Sync` (goroutine + channel) | без гонок (`-race`), финальное состояние согласовано |
| 6 | Клиент пуст (нет локальных изменений) | no-op, `nil` |

### 3.5. Локальное хранилище

| # | Сценарий | Ожидаемо |
|---|---|---|
| 1 | Сохранение локальных данных (зашифрованное) | файл/содержимое **не** в открытом виде |
| 2 | Загрузка локальных данных | round-trip через `security` |
| 3 | Выбор адаптера по конфигу | создаётся адаптер из `storage` по типу/формату из конфига |

### 3.6. Безопасность и логирование

| # | Сценарий | Ожидаемо |
|---|---|---|
| 1 | `slog`-логи | **нет** паролей, токенов, данных карт |
| 2 | Паники | не возникают при сетевых ошибках/таймаутах/битых ответах |

## 4. Дополнительные сценарии

- **Идемпотентность** (отдельная группа): повторный `CreateData` с тем же id/content — без дублей; повторный `Sync` — без потери данных.
- **Таймауты:** сетевые ошибки — с ограниченным временем ожидания (не зависает).
- **Race detector:** `go test -race` — все тесты чистые.

## 5. Критерии готовности

- [ ] покрытие ≥ 70%;
- [ ] все методы интерфейса `Client` покрыты (табличное покрытие);
- [ ] все ошибки (`ErrAuthFailed`, `ErrNotFound`, `ErrConflict`, `ErrNetwork`, `ErrServer`) — через `errors.Is`;
- [ ] идемпотентность и concurrency проверены;
- [ ] секреты не в логах.
