# tests-specs — `gophkeeper/internal/storage` (хранилища данных)

## 1. Общие положения

- Инструменты: `go test -v -race -cover`, `go.uber.org/mock`, GORM Gen (gorm.io/gen), PostgreSQL (для интеграционных тестов адаптера в Docker образе).
- Пакет нужен и серверу (персистентность), и клиенту (локальное хранилище).
- Имена: `TestStorage_<Адаптер>_<Сценарий>`, `TestStorage_Factory_...`, `TestStorage_CanStore_...`.
- Ключевые ошибки: `ErrNotFound`, `ErrConflict`, `ErrStorageFull`, `ErrCorruptData`.

## 2. Моки

| Зависимость | Заменитель |
|---|---|
| `data` (типы данных) | реальные (чистый пакет) |
| `security` (шифрование при записи) | gomock / реальные |
| GORM Gen repository (SQLite) | SQLite in-memory (`:memory:`) + GORM Gen |
| `storage.Storage` (интерфейс, для проверки контракта) | gomock (MockStorage) |

## 3. Группы тестов

### 3.1. Контракт интерфейса `Storage` (CRUD + List)

| # | Метод | Сценарий | Ожидаемо |
|---|---|---|---|
| 1 | `Save(item Item) error` | валидный объект | `nil`, объект записан |
| 2 | `Save` | конфликт версии | `ErrConflict` |
| 3 | `Get(id string) (Item, error)` | объект существует | `(Item, nil)` |
| 4 | `Get` | объекта нет | `ErrNotFound` |
| 5 | `Update(id, item) error` | валидный, владельца | `nil`, version+1 |
| 6 | `Update` | устаревшая версия | `ErrConflict` |
| 7 | `Delete(id) error` | свой объект | `nil`; `Get` → `ErrNotFound` |
| 8 | `List(ownerID string) ([]Item, error)` | свои объекты | только объекты владельца |
| 9 | `List` | пусто | пустой слайс, `nil` |
| 10 | Любой метод | владелец ≠ запроса | `ErrNotFound`/`ErrNotOwner` |

### 3.2. Фабрика — `NewStorage(cfg *Config) (Storage, error)`

| # | Сценарий | Ожидаемо |
|---|---|---|
| 1 | Валидный тип + формат | `(Storage, nil)` |
| 2 | Неизвестный тип хранилища | `ErrUnknownStorageType` |
| 3 | Неверный путь/нет прав | ошибка (permissions) |
| 4 | Неизвестный формат хранения | `ErrUnknownStorageType`/`ErrConfigInvalid` |

### 3.3. Адаптеры

#### File adapter (JSON/бинарный, `t.TempDir()`)

| # | Сценарий | Ожидаемо |
|---|---|---|
| 1 | `Save` → `Get` round-trip | объект идентичен |
| 2 | Запись в новый файл (нет файла) | файл создан |
| 3 | **Содержимое файла** | данные **не в открытом виде** (шифрованные, метаданные скрыты) |
| 4 | Повреждённый файл (bit-flip) | `ErrCorruptData` |
| 5 | Атомарность записи (симulação частичной записи) | нет частичных данных; `ErrStorageFull`/откат |
| 6 | Метаданные | сохранены и читаются |

#### In-memory adapter (для быстрых тестов/тестов конкурентности)

| # | Сценарий | Ожидаемо |
|---|---|---|
| 1 | CRUD + List | корректно |
| 2 | Параллельные записи/чтения (`-race`) | без гонок |
| 3 | Удаление во время чтения | без гонок/panic |

#### GORM Gen / SQLite in-memory (серверная персистентность)

| # | Сценарий | Ожидаемо |
|---|---|---|
| 1 | Миграции (авто) | применены без ошибок |
| 2 | CRUD + List (SQLite) | корректно |
| 3 | Транзакции: rollback при ошибке середины транзакции | данные не повреждены |
| 4 | Метаданные (jsonb/varchar) | сохранены и читаются |
| 5 | Конкурентные записи (goroutines) | без гонок, данные согласованы |

### 3.4. Целостность данных

| # | Сценарий | Ожидаемо |
|---|---|---|
| 1 | Сохранение объекта с метаданными | метаданные сохранены при `Get` |
| 2 | Объект с бинарным blob | round-trip — идентичный blob |
| 3 | Обновление метаданных (без изменения содержимого) | метаданные обновлены, содержимое не тронуто |

### 3.5. Логирование и безопасность

| # | Сценарий | Ожидаемо |
|---|---|---|
| 1 | Ошибки хранилища → `slog` | без раскрытия чувствительных данных |
| 2 | Данные карт/паролей в хранилище | зашифрованы, не в открытом виде |
| 3 | Паники | не возникают при битых данных |

## 4. Дополнительные сценарии

- **Атомарность:** запись не должна оставлять частичных данных при сбое (test с имитацией сбоя).
- **Расширяемость:** новый адаптер — без изменения интерфейса (Open/Closed).
- **Выбор хранилища/формата:** пользователь выбирает через конфиг — тесты на каждый тип/формат.

## 5. Критерии готовности

- [ ] покрытие ≥ 70%;
- [ ] каждый адаптер + фабрика покрыты;
- [ ] атомарность и race проверены;
- [ ] все ошибки (`ErrNotFound`, `ErrConflict`, `ErrStorageFull`, `ErrCorruptData`) — через `errors.Is`;
- [ ] данные не в открытом виде в файлах/БД (тесты-ассерты);
- [ ] godoc-документация.
