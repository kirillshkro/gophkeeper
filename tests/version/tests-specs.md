# tests-specs — `gophkeeper/internal/version` (версия/дата сборки)

## 1. Общие положения

- Инструменты: `go test -v -cover`.
- Пакет вспомогательный: номер версии + дата сборки, через `-ldflags`.
- Имена: `TestVersion_Version`, `TestVersion_String`, `TestVersion_BuildDate`.

## 2. Моки

| Зависимость | Заменитель |
|---|---|
| — | Пакет не имеет зависимостей; моки не нужны |
| ldflags | интеграционный smoke-тест (build с `-x main.version=...`) |

## 3. Группы тестов

### 3.1. `Version() string`

| # | Сценарий | Ожидаемо |
|---|---|---|
| 1 | `Version()` | non-empty, semver (regex `^\d+\.\d+\.\d+(-.*)?$`) |
| 2 | Pre-release/build-метки (если поддерживаются) | валидные semver |

### 3.2. `BuildDate() string`

| # | Сценарий | Ожидаемо |
|---|---|---|
| 1 | Задаётся через `-ldflags -x main.buildDate=...` | формат `YYYY-MM-DD` / ISO 8601 |
| 2 | Не задано (zero) | empty или fallback date, без panic |

### 3.3. `BuildCommit() string` (необязательно)

| # | Сценарий | Ожидаемо |
|---|---|---|
| 1 | Задаётся через ldflags | формат hash (SHA-1/SHA-256) |
| 2 | Не задано | empty, `String()` всё ещё работает |

### 3.4. `String()` / `Short()`

| # | Сценарий | Ожидаемо |
|---|---|---|
| 1 | `String()` | "версия + дата сборки (+ commit)" |
| 2 | `Short()` | сокращённый формат (e.g. версия только) |
| 3 | `nil`/empty version | без panic, корректный вывод |

### 3.5. Встраивание через ldflags (интеграция)

| # | Сценарий | Ожидаемо |
|---|---|---|
| 1 | Build с `-x main.version=9.9.9-rc1` | версия в бинарном файле |
| 2 | Build с `-x main.buildDate=2026-11-11` | дата в бинарном файле |
| 3 | Build без ldflags (default) | default values, без panic |
| 4 | Запуск CLI `version` / сервера | вывод версии и даты сборки |

## 4. Дополнительные сценарии

- **Статичность:** все getter — детерминированные, без побочных эффектов.
- **Несуществительность:** пакет не зависит от других пакетов модуля.
- **Stability:** изменения API — только additive (новые getter без изменения старых).

## 5. Критерии готовности

- [ ] покрытие ≥ 70%;
- [ ] все getter (`Version`, `BuildDate`, `BuildCommit`, `String`, `Short`) — покрыты;
- [ ] `nil`/empty ввод — без panic;
- [ ] godoc-документация;
- [ ] пакет независим (не зависит от других пакетов).
